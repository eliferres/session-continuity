# Checkpoint — <one-line arc name>

Read this file in full before doing anything else. It is written for a
reader with zero context: every path, command, and identifier is exact,
every date is absolute, and nothing here assumes you remember a thing.

Rewrite the whole file each time, replacing the hints below. Keep every
section even when the honest content is "none" — a missing section reads
as forgotten, an empty one reads as answered.

## Objective

What the work is ultimately for, in one or two lines. Not the task at
hand — the outcome that makes the task worth doing.

## State

Per workstream: done and verified, in flight, or blocked. Name the exact
files, commands, and outputs. "Migrated the config loader" is a summary;
"`src/config.py` reads the new schema, `tests/test_config.py` green on
Python 3.11, the CLI still reads the old keys" is state.

## Decisions and why

Every ruling made, each with the reasoning that produced it. These are
settled: the next session inherits the conclusion and the argument, so it
never reopens a closed question or re-derives a tradeoff you already paid
for.

## Open threads

What happens next, in priority order, each concrete enough to act on
cold. Anything blocked names what it is blocked on and who or what
unblocks it.

## Gotchas and dead ends

Approaches tried and rejected, each with a one-line why. Traps hit and
the fix for each. Things that look wrong but are correct. This section is
the one that saves the most time and gets skipped the most often — a dead
end you fail to record is one the next session pays for again.
